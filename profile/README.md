### Word and PowerPoint files in pure Rust

Read, write, edit, compare and render `.docx` and `.pptx`, from Rust, the command line or Python.
No Office, no LibreOffice, no conversion service.

</div>

| Repository | What |
| --- | --- |
| [oxoffice](https://github.com/oxoffice-dev/oxoffice) | the library: Rust crates, the `oxoffice` command line and the `oxoffice` Python package |
| [oxoffice-skills](https://github.com/oxoffice-dev/oxoffice-skills) | Word and PowerPoint skills for AI agents, built on oxoffice |

```bash
curl -fsSL https://github.com/oxoffice-dev/oxoffice/releases/latest/download/install.sh | sh
```

Every release ships checksums and a signed build provenance. oxoffice is a friendly fork of
[rdocx](https://github.com/tensorbee/rdocx), MIT licensed.
